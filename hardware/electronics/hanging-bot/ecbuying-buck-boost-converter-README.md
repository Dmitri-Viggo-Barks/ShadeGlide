# Hanging Bot's Buck & Boost Converters Information
## Modules
The hanging bot's buck and boost converter (BBC) components are breakout modules manufactured by <strong>EC Buying</strong>. Pins of the IC are configured to have only 4 or 5 simplified pins in the module. Both of the BBC's ICs are difficult to confidently identify, so the project will only refer to the BBCs by their breakout module specifications.

The used BBC breakout modules:
- <strong>EC Buying 3.3V 600mA DC Output Buck & Boost Converter Breakout Module</strong>
- <strong>EC Buying Adjustable 1V~15V 700mA DC Output Buck & Boost Converter Breakout Module</strong>

## EC Buying 3.3V 600mAh DC Output Buck & Boost Converter Breakout Module
### Specifications
Specification details are taken from EC Buying's Shopee product listing. <br/> <br/>
Input Voltage: 2.5V~15V DC <br/>
Output Voltage: 3.3V <br/>
Output Current: 600mA (Max) <br/>
Output Ripple: <50mV <br/>
Output Accuracy: ±0.1V <br/>
Efficiency: ~75% <br/>
Working Temperature: -20°C~85°C <br/>
Relative Humidity: 20%~90%
### Pins
- IN+
- IN-
- OUT+
- OUT-


## EC Buying Adjustable 1V~15V 700mAh DC Output Buck & Boost Converter Breakout Module
### Specifications
Specification details are taken from EC Buying's Shopee product listing. <br/> <br/>
Input Voltage: 3V~15V DC <br/>
Output Voltage: 1V~15V DC, adjustable via on-board screw potentiometer <br/>
Output Current: 700mA (Max) <br/>
Output Power: 5W (Max) <br/>
Quiescent Current: 1mA (Typical Value), quiescent current grows as output voltage does <br/>
Efficiency: ~85%

### Pins
- IN+
- IN-
- OUT+
- OUT-
- EN

EN enables the control terminal, which needs to be connected to the IN  module for output. <br/>
