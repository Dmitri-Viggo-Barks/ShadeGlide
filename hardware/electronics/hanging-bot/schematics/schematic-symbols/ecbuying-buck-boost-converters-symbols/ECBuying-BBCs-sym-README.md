## ECBUYING Buck & Boost Converters KiCAD Symbols Library
The library only contains symbols for the DC-DC converter breakout modules present in the hanging bot. This library does not house all of ECBUYING's sold Buck & Boost Converter boards and modules.

Contained BBC schematic symbols:
- `ECBuying_S08_V5_3V3`: fixed 3.3V output module, 4 pins
- `ECBuying_Adjustable_5Pin`: adjustable-output module, 5 pins including EN

### `ECBuying_S08_V5_3V3`
Pins:
- IN+
- IN-
- OUT+
- OUT-

### `ECBuying_Adjustable_5Pin`
Pins:
- IN+
- IN-
- OUT+
- OUT-
- EN
