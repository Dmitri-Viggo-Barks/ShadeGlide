# Project Journals

## Uses of Journals
A journal should discuss on the happened changes or updates done to the overall project. Its content's nature can be general or specific. <br/>
<br/>
Each journal entry should only be made after each project's milestone or major development, it should not discuss individual developments. Individual developments can be discussed together in one journal entry.

## Filename
each journal entry must follow the format: <br/> `<journal sequence number>-<title in dash-spaced>.md`

Journal sequence number be in a 3 digit format with zeroes padding to spaces unused. This refers to the sequence of the journal entry in relation to previous entries.

### Invalid Examples:
&emsp; `01-title.md` <br/>
&emsp; `4-title_word-title_word.md` <br/>
&emsp; `000175-title.md` <br/>

### Valid Examples:
&emsp; `001-title.md` <br/>
&emsp; `004-title_word-title_word.md` <br/>
&emsp; `175-title.md` <br/>
<br/>
